# Search Tab Organization

The terms Search uses for open tabs and their groups.

## Language

**Tab group**:
A named, colored set of open tabs. Search restores groups with normal tabs at launch; a group that held only private tabs ends with the run.
_Avoid_: Folder

**Collapsed tab group**:
A tab group whose tabs are hidden from the tab row or sidebar. Its active tab can stay on screen.

**Default group name**:
A generated label in the form "Group N" for a group that the user has not named. N is its position among such groups and changes when those groups move or leave.
